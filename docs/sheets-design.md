# Googleスプレッドシート設計仕様

管理画面として使う1つのスプレッドシートに、以下の10シートを作成します。
実際の作成は `sheets/apps_script_bootstrap.gs` を使えば、空のスプレッドシートに
ワンクリックで全シート・見出し・入力規則(ドロップダウン)を自動生成できます
(手順は `docs/setup/02_google_sheets.md` を参照)。

## ステータスの一覧(投稿カレンダーで使用)

`下書き → AI校閲済み → 承認待ち → (承認 / 修正 / 却下) → 投稿予約 → 投稿済み / エラー`

**「承認」以外のステータスの投稿は絶対に公開しません。**

## 1. 設定

| 列 | 内容 |
|---|---|
| 項目 | 設定名(例: MONTHLY_BUDGET_JPY) |
| 値 | 設定値 |
| 説明 | 何のための設定か |
| 最終更新日 | 更新日 |

初期行の例: `MONTHLY_BUDGET_JPY / 3000 / 月間API予算上限(円)`、
`WEEKLY_POST_TARGET / 4 / 週間の投稿目標本数`、
`IG_ACCOUNT_MODE / test / test または production`、
`YT_ACCOUNT_MODE / test / test または production`

## 2. 企画候補

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| 作成日 | 企画エージェントが作成した日 |
| タイトル案 | 投稿タイトル案 |
| 切り口 | 企画の切り口説明 |
| フォーマット | Instagramカルーセル / YouTube Shorts / 比較記事 |
| 出典URL | リサーチ結果の出典 |
| 専門性・需要・収益性・独自性・リスク | 各1〜5点 |
| 合計スコア | 5項目の合計 |
| 重複チェック | 重複なし / 類似あり(理由) |
| 要人間承認 | TRUE / FALSE |
| 承認理由 | 要人間承認がTRUEの場合の理由 |
| ステータス | 検討中 / 採用 / 却下 |

## 3. 投稿カレンダー

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| 企画候補ID | 2.のID参照 |
| 投稿予定日時 | `YYYY-MM-DD`形式。この日付(JST)になるまで「承認」でも投稿されない(2026-09-14〜)。空欄の場合は承認され次第すぐ投稿される。この列を手動で書き換えれば、投稿日を個別に前後させられる |
| プラットフォーム | Instagram / YouTube Shorts |
| アカウント種別 | test / production |
| ステータス | 上記9ステータスのいずれか(ドロップダウン) |
| 担当エージェント | どのエージェントが最後に更新したか |
| 最終更新日時 | 自動更新 |
| 備考 | 自由記入 |

週次パイプラインは、週4本を自動で月・水・金・日に振り分けて「投稿予定日時」に設定する
(`scripts/weekly_pipeline.py` の `POST_WEEKDAYS`)。曜日構成を変えたい場合はこの定数を編集する。

## 4. 投稿原稿

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| 投稿カレンダーID | 3.のID参照 |
| Instagramキャプション | 投稿文(ハッシュタグ含む) |
| カルーセルスライド | スライドごとの見出し・本文(JSON文字列) |
| YouTube台本 | Shorts用ナレーション原稿 |
| CTA | 誘導文言 |
| PR表記有無 | TRUE / FALSE |
| 校閲結果 | 校閲エージェントの指摘サマリー |
| 修正指示 | 人間からの修正コメント |
| バージョン | 修正のたびに+1 |
| 更新日時 | 自動更新 |

## 5. 記事

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| タイトル | 記事タイトル |
| 本文 | 本文(長文はGoogle Docsリンクでも可) |
| 公開URL | Cloudflare Pages上のURL |
| 公開ステータス | 下書き / 公開済み |
| 関連アフィリエイト案件ID | 6.のID参照(該当する場合) |
| 出典一覧 | 出典URLの一覧 |
| 公開日 | 公開日 |
| 更新日 | 更新日 |

## 6. アフィリエイト案件

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| サービス名 | 案件名 |
| ジャンル | 求人媒体 / 人事SaaS 等 |
| 報酬条件 | 成果報酬の条件 |
| PR表記文言 | 使用する広告表記の文言 |
| 承認状況 | 承認待ち / 承認 / 却下(ドロップダウン) |
| 承認日 | 承認日 |
| 契約リンク | 案件詳細・契約ページ |
| 備考 | 自由記入 |

新しいアフィリエイト案件は、必ずこのシートで「承認待ち」として登録し、人間が「承認」に変更するまで
原稿・投稿には使用しません。

## 7. 投稿実績

| 列 | 内容 |
|---|---|
| ID | 一意のID |
| 投稿カレンダーID | 3.のID参照 |
| プラットフォーム | Instagram / YouTube Shorts |
| 投稿URL | 実際の投稿URL |
| 投稿日時 | 投稿された日時 |
| 再生数・表示数・保存数・クリック数・問い合わせ数 | 各指標 |
| 取得日 | 数値を取得した日 |

## 8. 分析

| 列 | 内容 |
|---|---|
| 週 | 対象週(例: 2026-W38) |
| 上位テーマ・上位構成・上位冒頭表現 | 成績上位から抽出した傾向 |
| 下位テーマ傾向 | 成績下位の傾向 |
| 来週への提案 | 分析エージェントの提案 |
| 作成日 | 作成日 |

## 9. エラーログ

| 列 | 内容 |
|---|---|
| 発生日時 | エラー発生日時 |
| エージェント/処理 | どこで発生したか |
| エラー内容 | エラーメッセージ |
| 対象ID | 関連する投稿カレンダーID等 |
| リトライ回数 | 再試行した回数 |
| 対応状況 | 未対応 / 対応中 / 解決済み |
| 対応者 | 人間が対応した場合の氏名 |
| 解決日時 | 解決した日時 |

個人情報(応募者情報・認証情報)はこのシートに絶対に書き込みません。

|---|---|

| 来週の申し送り | 次週への引き継ぎ事項 |
| 作成日 | 作成日 |
