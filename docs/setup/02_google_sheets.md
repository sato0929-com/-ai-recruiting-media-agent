# 手順2: 管理用Googleスプレッドシートの作成

企画候補・投稿カレンダー・承認作業などを行う「管理画面」を、Google スプレッドシート上に
自動生成します。10個のシートが一度に作られるので、手作業で列を作る必要はありません。

## 手順

1. ブラウザで `https://sheets.google.com` を開く(Googleアカウントでログインした状態)。
2. 「**空白**」のスプレッドシートを新規作成する。
3. 左上のファイル名(「無題のスプレッドシート」)をクリックし、
   `採用AIメディア運営シート` のような分かりやすい名前に変更する。
4. 上部メニューの「**拡張機能**」→「**Apps Script**」をクリックする(新しいタブが開きます)。
5. 開いたApps Scriptの編集画面に、デフォルトで入っている `function myFunction() {...}` の
   コードを全て選択して削除する。
6. このリポジトリの `sheets/apps_script_bootstrap.gs` の中身を全てコピーし、
   6.で空にした編集画面に貼り付ける。
7. 画面左上の「**保存**」(フロッピーディスクのアイコン)をクリックする。
8. 保存すると、プロジェクト名を聞かれるので `sheets-bootstrap` などと入力してOKする。
9. 上部の関数選択プルダウンで「**setupSpreadsheet**」が選ばれていることを確認する
   (デフォルトで選ばれているはずです)。
10. 「**実行**」ボタン(▶マーク)をクリックする。
11. 初回のみ「承認が必要です」という画面が出るので、「**権限を確認**」→
    自分のGoogleアカウントを選択→「**詳細**」→
    「**(プロジェクト名)に移動(安全ではないページ)**」→「**許可**」の順にクリックする
    (これは自分だけが作った自分のスクリプトなので問題ありません)。
12. 実行が終わると「セットアップ完了: 10シートを作成しました。」という画面が出る。
13. 元のスプレッドシートのタブに戻り、下部に10個のシート(設定・企画候補・投稿カレンダー…)
    が並んでいることを確認する。

## スプレッドシートIDの控え方(フェーズ2後半で使用)

1. スプレッドシートを開いた状態で、ブラウザのアドレスバーのURLを確認する。
2. `https://docs.google.com/spreadsheets/d/【ここの文字列】/edit` の
   【ここの文字列】の部分をコピーする。
3. `.env` ファイルの `GOOGLE_SHEETS_SPREADSHEET_ID` にこの値を設定する(手順は別途案内します)。

## 確認方法

- シート下部のタブに「設定」「企画候補」「投稿カレンダー」「投稿原稿」「記事」
  「アフィリエイト案件」「投稿実績」「分析」「エラーログ」「週間レポート」の
  10個が表示されていればOKです。
- 「投稿カレンダー」シートの「ステータス」列のセルをクリックすると、
  ▼マークが出てドロップダウンで選択できることを確認してください。
