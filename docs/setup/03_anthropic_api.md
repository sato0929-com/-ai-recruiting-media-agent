# 手順3: Anthropic APIキーの発行と予算上限の設定

これは無人実行(GitHub Actionsが夜間・週次で動く部分)のためだけに使うキーです。
Claude Pro(claude.ai)の契約とは別物で、ここで初めて少額の従量課金が発生します。

このシステムには「二重の安全装置」があります。
- **Anthropic側の安全装置**: この手順で設定する「使用上限(Spend Limit)」。上限に達すると
  Anthropic側で強制的にAPIが使えなくなります。
- **本システム側の安全装置**: `scripts/budget_guard.py` が月間3,000円の80%で新規生成を停止、
  100%で全停止します。

**最初の運用は月5ドル(ご希望により当初の20ドル案から変更)を上限にします。**
5ドルは約750〜800円相当で、本システム側の3,000円上限よりかなり小さいため、当面は
Anthropic側の5ドル上限が先に効く、より保守的な設定になります。慣れてきたら、
Anthropicの上限を20ドル程度まで引き上げ、本システム側の3,000円ロジックを主とする
運用に切り替えることもできます(その際はご相談ください)。

## 手順(このAnthropic APIキー発行の手順「だけ」を今回行います。この後のGitHub Secrets登録・
Googleスプレッドシート設定は、この手順が完了してから改めて画面単位でご案内します)

1. ブラウザで `https://console.anthropic.com` を開き、Googleアカウント等でサインアップ/ログインする。
2. 左メニューの「**Settings**」→「**Billing**」を開く。
3. クレジットカードを登録する(従量課金の支払い用)。
4. 同じ「Billing」画面にある「**Usage limit**」または「**Spend limit**」の項目で、
   月間の上限金額を **5ドル** に設定する(米ドル建てです)。
5. 左メニューの「**Settings**」→「**API Keys**」を開く。
6. 「**Create Key**」ボタンを押す。
7. キーの名前(例: `recruiting-media-actions`)を入力して作成する。
8. 表示された `sk-ant-` から始まる文字列を **その場でコピーする**(再表示できないので注意)。
9. このキーは絶対にチャット・メール・コードに直接貼り付けない。次にご案内する
   GitHub Secretsの登録画面に、Anthropic公式画面からコピーした直後に直接貼り付けてください。

## 確認方法

- 「API Keys」画面に、作成したキーの名前が表示されていればOKです。
- 「Billing」→「Usage」画面で、現在の利用額が0ドルであることを確認してください。
